# Band Eight — IELTS Academic coach

A local-first study studio for **IELTS Academic Band 8+**. It builds a plan from the days left until your test, drills every official question type, marks mocks, and tells you what to fix next.

## Run

```bash
cd ielts-band8
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## What it covers

- **Four papers** in official Academic format: Listening, Academic Reading, Academic Writing, Speaking
- **Question types** as published by IELTS.org / British Council / IDP
- **Topic atlas** — high-frequency Academic clusters examined as L / R / W / S
- **Adaptive plan** — foundation → build → intensify → simulate → taper, based on exam date
- **Mocks** with official clocks and official-style score conversion (≈35–36/40 → Band 8 on L/R)
- **Writing & Speaking** rubric estimates (Task Achievement/Response, CC, LR, GRA; plus Speaking pronunciation caveat)
- **Feedback that changes** when you have 60, 30, 14, 7 or 2 days left
- **Official desk** — live links to IELTS.org, British Council, IDP, Cambridge

Practice items are **original** and exam-shaped. They are not leaked Cambridge keys. Use official partners and Cambridge books for additional full tests.

Scores stay in your browser (`localStorage`). Writing/Speaking bands are coaching estimates, not examiner certificates.
